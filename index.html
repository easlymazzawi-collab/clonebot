Workflow
Sơ đồ luồng hoạt động đầy đủ
💡
Kiến trúc hệ thống
Hệ thống gồm 3 thành phần phối hợp: Userbot clone nội dung sang forum mới, Bot lưu media gốc và trả về ẩn danh, Caption Editor nhúng link bot vào mỗi bài.
🔄 Luồng Clone (Userbot)
1
Kết nối Forum Nguồn
Userbot xác thực qua API ID + Hash + số điện thoại. Preload toàn bộ danh sách topics và metadata.
2
Clone cấu trúc Topics (Phase 1)
Tạo topic tương ứng ở Forum Đích với cùng tên, màu icon, emoji premium. Match theo title nếu đã tồn tại. Lưu topic_map để resume.
3
Forward Messages (Phase 2)
Duyệt từng topic theo iter_messages(reply_to=topic_id). Gom album theo grouped_id → 1 API call. Batch 50 msg đơn/call. Resume qua state file.
4
Xử lý Video → Thumbnail
Tin nhắn chứa video: chỉ lấy thumbnail (ảnh đại diện). Không clone file video nặng để tiết kiệm quota và tốc độ. Video gốc vẫn lưu ở forum nguồn.
5
Ẩn Nguồn (drop_author)
Dùng ForwardMessagesRequest với drop_author=True → ẩn "Forwarded from". Giữ nguyên 100% nội dung: emoji premium, bold, italic, album, spoiler.
🤖 Luồng Bot (Media Serve)
1
Bot lấy Media từ Forum Nguồn
Sau khi clone, bot dùng Userbot để lấy file_id gốc từ mỗi album/media ở forum nguồn. Lưu vào database mapping: msg_id → [file_id_list].
2
Tạo Link Bot cho mỗi bài
Mỗi bài cloned có unique token: t.me/YourBot?start=alb_. Token map tới danh sách file_id gốc. Lưu vào JSON/SQLite.
3
Nhúng Link vào Caption
Caption Editor tự động thêm vào cuối mỗi bài cloned: [caption gốc] — Nhấp vào link này để xem: t.me/Bot?start=alb_XXX
4
Người dùng bấm link Bot
Bot nhận /start alb_XXX → tra database → lấy file_id list → gửi album gốc dùng send_media_group(). Không kèm tên nguồn, không forward header.
5
Trả Album Nguyên Vẹn
Bot gửi đúng album gốc (không tách lẻ), giữ caption gốc, ẩn nguồn. Flood wait tự retry. Thống kê số lượt xem per bài.
